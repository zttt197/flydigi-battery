# flydigi-battery

飞智（Flydigi）八爪鱼手柄电量显示工具。

只做一件事：**在系统托盘显示手柄剩余电量**。不接管按键、不做映射、不装驱动。

## 协议速查

| 项 | 值 |
|---|---|
| VID/PID | `0x37D7`（新）/ `0x04B4:0x2412`（旧） |
| 请求 | `RR 5A A5 01 02 00` + 补 0 到 32 字节 |
| 回复 | 32 字节，剥掉可能的 Report ID 后以 `5A A5 01` 开头 |
| 电量 | `payload[11]`：高半字节状态（0 放电 / 1 充电 / 2 充满），低半字节档位 |
| 百分比 | 档位 × 20（Apex6 为 × 10），充满直接 100% |
